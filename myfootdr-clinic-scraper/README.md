# MyFootDr Clinic Scraper

A web scraper designed to harvest data from MyFootDr clinics.

## Directory Structure
- `data/`: Stores raw and processed CSV outputs
- `logs/`: Log files to track scraping errors/progress
- `src/`: Source code directory
- `run.py`: Simple runner script

## Usage
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the scraper:
   ```bash
   python run.py
   ```
